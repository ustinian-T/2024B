2024高教社杯国赛B题——问题二 Python代码说明

一、文件
1. q2_model.py：完整可运行主程序（PyCharm 直接运行即可）
2. requirements_q2.txt：依赖
3. ../结果输出/：默认输出目录，按默认参数运行后生成的结果CSV（不含绘图）

二、安装
pip install -r requirements_q2.txt

三、运行
python q2_model.py

默认：
- Monte Carlo：每个情形100000笔订单
- 单参数灵敏度：每个参数101个网格点，并用二分法精确细化策略切换临界值
- p2-L二维灵敏度：31×31网格
- 输出目录：脚本所在目录的 ../结果输出/，即 求解代码/第二问/结果输出/

指定输出目录（绝对路径）：
python q2_model.py --output-dir D:/your/output

快速自测：
python q2_model.py --quick

跳过Monte Carlo：
python q2_model.py --skip-mc

四、模型实现
- 解析概率传播 + 几何分布：作为z=0退化基准
- 信息保持型闭环Bellman–Markov：作为主模型
- 原始2^6=64策略生成，z=0时r1,r2规范化，共40个有效六位策略
- 每个四位生产策略(x1,x2,y,z)内部自动选择最优回收规则(r1,r2)，最终比较16个不同生产策略
- 仅对从起始状态N真正可达的暂态状态计算谱半径，避免不可达自循环状态误判

五、确定性检验
程序会自动执行并在失败时抛出异常：
- z=0 Bellman解 vs 几何分布闭式解，相对误差<1e-10
- 六情形参考最优策略与利润复现
- Bellman残差、成本分解闭合、吸收概率=1
- 极端情形和永久循环策略检验

六、Monte Carlo说明
Monte Carlo只做独立验证，不参与优化。程序输出理论值、模拟均值、标准误和95%置信区间。
单次95%置信区间本身有5%概率不覆盖真值，因此六个情形同时验证时，偶尔出现1个情形不落在95%区间并不意味着解析模型错误；应同时结合z-score、解析退化和Bellman残差判断。
